# 新浪投诉搜索

## 案例概况
- 难点：搜索接口 SHA-256 签名与会话 Cookie。
- 已记录结果：请求代码生成签名并分页采集投诉数据。
- 方案：根据关键字、分页参数、时间戳、随机串和固定盐构造签名。

## 解决思路
规范化搜索词、分页和时间字段，按接口拼接规则计算 SHA-256 摘要并放入 `signature` 参数。可选 Cookie 从 `TOUSU_SINA_COOKIE` 环境变量读取，不将个人会话写入代码。

## 代码
- `code/signature.py`：标准库签名参数生成模块。

## 依赖与限制
Python 3.10+，签名模块只用标准库。调用搜索接口、解析结果和分页逻辑需由客户端按实际接口接入；如接口要求登录态，请自行注入有效授权 Cookie。
