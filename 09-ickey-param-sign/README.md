# ICKEY / 云汉搜索接口参数

## 案例概况
- 挑战类型：搜索接口动态参数 `p`，并依赖页面下发的 CSRF、Cookie 和动态 JS。
- 方案：从商品详情页取得会话与 CSRF，加载搜索签名脚本，在 Node.js 环境执行动态函数并计算 `p`。
- 成功判据：生成的 `p` 随时间戳、分类 ID 更新并用于搜索接口分页请求；运行时仍应检查接口业务响应。

## 解决思路
1. 请求详情页建立会话，提取 `_csrf` 和 `font_ident`。
2. 请求搜索站点下发的动态脚本，确认预期签名函数存在。
3. 在 JavaScript 执行环境中运行页面脚本；按 `Base64(category_id)`、时间戳、MD5 中间值和动态函数结果构造参数 `p`。
4. 发送搜索请求时复用 Cookie、CSRF 与动态参数；每页按新时间戳重新计算。

## 代码
- `code/ickey_signer.py`：初始化会话并生成搜索参数。
- `code/ickey_challenge.js`：动态脚本执行所需的通用摘要/辅助函数。

## 依赖与限制
Python 3.10+、`requests`、`PyExecJS`、Node.js、`lxml`。搜索接口 URL 或签名脚本发生变化时需重新定位函数和输入拼接规则。签名器提供参数生成，不包含完整采集、存储和并发调度。
