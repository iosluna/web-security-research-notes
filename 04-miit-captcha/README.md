# 工信部电信业务综合管理企业查询

## 案例概况
- 挑战类型：图形验证码与会话状态校验。
- 已记录结果：两个独立实现均包含识别、查询和响应解析闭环；运行时应进一步检查业务码与结果完整性。
- 方案：同一 `requests.Session` 取验证码、识别并提交查询；另一实现也记录了独立 CookieJar、UA/代理重试和业务字段验收。

## 解决思路
读取验证码接口返回的 Base64 图片，用 `ddddocr` 识别并校验格式，再提交企业查询。验证码或响应解析失败时有限重试；检测会话失效后清理 Cookie 并重新取码。成功条件是查询结果可解析且包含预期业务字段，而非只看 HTTP 200。

## 代码
- `code/captcha_client.py`：独立 Python 请求客户端和验证码识别流程。

## 依赖与边界
Python 3.10+、`requests`、`ddddocr`。运行示例：`python captcha_client.py "企业名称"`。此简化模块保留核心取码与查询逻辑；与原采集程序相比，任务调度、数据存储和代理控制需由调用方自行实现。
