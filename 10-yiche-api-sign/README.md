# 易车汽车参数接口

## 案例概况
- 挑战类型：汽车参数详情 API 的 `x-sign` 请求签名。
- 方案：将 `cid`、紧凑 JSON 参数、固定签名后缀和毫秒时间戳按顺序拼接后计算 MD5。
- 成功判据：签名、时间戳、GUID 请求头和查询参数按接口要求一起发送；收到响应后需再检查业务内容。

## 解决思路
从车型参数接口代码中抽取签名构造：`param` 使用紧凑 JSON；签名原文为 `cid=508&param=<JSON><签名后缀><timestamp>`；计算 MD5 后设置 `x-sign`，同时传入 `x-timestamp` 与新生成的 `x-user-guid`。

## 代码
- `code/yiche_sign.py`：构造签名 URL 与请求头。

## 依赖与限制
Python 3.10+，仅用标准库。模块不发送请求；调用方负责提交 GET 请求并校验响应。签名后缀和字段顺序来自既有请求实现，接口变更后需重新验证。
